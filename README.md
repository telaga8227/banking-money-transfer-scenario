# Banking Money Transfer Simulation

A clean, object-oriented Python program with banking logic. It handles account deposits, withdrawals, and secure funds transfers between users with built-in error handling.

## Features
* *Object-Oriented Design*: Utilizes a BankAccount class to manage individual user account numbers and  balances.
* *Transaction Safety*: Built in logic to prevent overdrawing accounts, providing instant feedback for insufficient funds.
* *Error Handling*: Uses try-except blocks within transfers to catch runtime validation errors cleanly.

## How It Works
The script executes a transfer between accounts while tracking real-time balance updates in the console.

## Technologies Used
* Python 3
